SQL Mastery Roadmap: Beginner to Expert

38 days in 7 levels: database fundamentals, basic and intermediate SQL, advanced SQL, database engineering, interview problem solving and three real projects. Each day has a lesson (concepts, internals, mistakes, interview questions, revision points) and hands-on problems that run in your browser.

What runs in the browser, and what does not

Queries run on SQLite (via WebAssembly) with a compatibility layer so common MySQL 8 syntax works: CREATE DATABASE/USE, AUTO_INCREMENT, DESCRIBE, SHOW TABLES, TRUNCATE, CONCAT, IF, DATEDIFF, DATE_ADD, TIMESTAMPDIFF, DATE_FORMAT, ON DUPLICATE KEY UPDATE, INSERT IGNORE, MINUS, DELIMITER and more. Everything in Levels 2 to 4, views, triggers, transactions with savepoints, indexes with EXPLAIN, recursion and window functions is hands-on.

Concept-only (no real server in a browser): stored procedures and user-defined functions, real multi-session isolation levels and locking, materialized views, MODIFY COLUMN, and hash/merge join internals. They are taught with MySQL code to read, multiple-choice questions, and a step-through simulator on the Lab page. For a full MySQL 8 setup, install it locally and replay the lesson examples.

Tools around the roadmap
